# Variable & Constant

**Merkregel: `=` bindet einen Namen an ein Ergebnis.**

## Variable (Variable)

Ein Name, der an ein Objekt gebunden ist.

```python
provider = "claude"
```

- `provider` → variable name (Variablenname)
- `"claude"` → value (Wert)
- `=` → assignment (Zuweisung)

## Constant (Konstante)

Soll nicht neu zugewiesen werden.

```python
MAX_ATTEMPTS = 5
```

Großschreibung ist eine Konvention. Python erzwingt sie nicht.
